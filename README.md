## 4. Reinterpreting Gravity & Momentum / 重力と運動量の数理的見方

  * 物体は連続空間を滑らかに移動しているのではなく、1コマごとに位相角 $\Delta \theta = 2\pi / n$ だけ次の回転状態へ切り替わっています。この**1コマあたりの回転の進み具合（フレームレート）**を連続空間の物差しに換算したものが「運動量・角運動量」です。
* **Gravity as Orthogonal Projection Gradient toward a Zero-Seat (重力 ＝ ゼロ席への直交射影勾配):**
